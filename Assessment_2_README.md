# Auralis Nova – Promotional Key Visual

## Project Overview
This project creates a premium promotional key visual for a fictional consumer audio brand, **Auralis Nova**. The image was created using ComfyUI by combining AI-generated product imagery, a custom-generated cinematic background, and image editing to produce a polished advertising visual.

## Tools & Models Used
- ComfyUI
- FLUX
- Qwen Image Edit
