# Kanban Board

## Project Overview
A responsive Kanban task management board built using HTML, CSS, and JavaScript. The application supports drag-and-drop task management with local storage persistence and works entirely offline.

## Features
- Drag and drop tasks between columns
- Add, edit, and delete tasks
- Search and priority filter
- Due date with overdue highlighting
- LocalStorage persistence
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Installation
Download the project and open `index.html` in any modern web browser.

## Known Limitations
- Single-user application
- Data is stored locally in the browser
- No backend or cloud synchronization
